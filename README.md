# Simple Interest Calculator

## Description

The Simple Interest Calculator is a simple program used to calculate the interest earned or paid on a principal amount over a specific period at a fixed rate of interest.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:

* P = Principal Amount
* R = Annual Rate of Interest
* T = Time Period (in years)

## Features

* Accepts principal amount as input.
* Accepts annual interest rate.
* Accepts time period in years.
* Calculates simple interest.
* Displays the total amount (Principal + Interest).

## Example

**Input:**

* Principal = 10000
* Rate = 5%
* Time = 2 years

**Calculation:**

SI = (10000 × 5 × 2) / 100

SI = 1000

**Output:**

* Simple Interest = 1000
* Total Amount = 11000

## Applications

* Basic financial calculations.
* Loan interest estimation.
* Understanding interest calculations.
